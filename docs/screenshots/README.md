Notes

- Board shots stay PNG so the UI text stays crisp; the two broadcast frames are JPEG (quality 85) to keep the repo light.
- Each board must be captured in the language of the README that shows it — 简体 uses 潘妮, 繁體 uses 佩妮.
- Boards are 560 px wide for a 260 px table cell (2× for retina). Broadcast frames are 1000 px wide for a 480 px cell.
- Layout is two columns: the portrait board on the left with `rowspan="2"`, the two landscape frames stacked on the right.
